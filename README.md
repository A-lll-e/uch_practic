# Умный офис

Учебный проект по разработке виртуальной системы мониторинга и
автоматизации офисного помещения.

**Дисциплина:**  ПМ03 «Участие в разработке приложений взаимодействия с интеллектуальными интегрированными системами»\
**Специальность:** 09.02.08 Интеллектуальные интегрированные системы\
**Группа:** 54-15\
**Номер в журнале:** 14

## Описание проекта

Проект посвящён созданию прототипа умного офиса, который собирает данные
о температуре и влажности, управляет вентиляцией серверной и ведёт
историю измерений.

Виртуальная инфраструктура развёрнута в GNS3. В качестве операционных
систем используются РЕД ОС 8 и Windows Server 2019.

## Архитектура системы

Система состоит из нескольких виртуальных узлов, каждый из которых
выполняет отдельную задачу.

  Узел   Роль в системе
  ------ -----------------------------------------------------------
  WIN    Рабочее место администратора на базе Windows Server 2019
  IOT    Эмуляция датчиков и вентилятора с помощью Node-RED
  CTRL   Приём телеметрии и публикация метрик
  DB     Сохранение истории измерений в SQLite
  MON    Мониторинг и визуализация с помощью Prometheus и Grafana
  RTR    Маршрутизация между VLAN и обеспечение выхода в интернет
  SW     Коммутация устройств и логическое разделение сети на VLAN

## Логика работы

На виртуальном узле IOT в Node-RED реализованы три устройства:

-   **TEMP-01** --- виртуальный датчик температуры серверной.
-   **HUM-01** --- виртуальный датчик влажности рабочей зоны.
-   **FAN-01** --- модель вентилятора серверной.

Датчики формируют и отправляют показания с периодичностью 5 секунд.

Node-RED управляет состоянием вентилятора в зависимости от температуры:
при выполнении заданного условия вентилятор включается (`ON`), в
противном случае выключается (`OFF`).

Полученные данные передаются на узел CTRL для дальнейшего мониторинга, а
также на узел DB, где сохраняются в базе SQLite.

Prometheus получает метрики от CTRL. Grafana использует эти данные для
отображения состояния системы на панели мониторинга. Если от датчика не
поступают данные более 20 секунд, Grafana формирует оповещение и
отправляет уведомление администратору по электронной почте.

## Адреса сервисов

Для доступа к веб-интерфейсам и сервисам используются следующие адреса:

  Компонент                 URL
  ------------------------- -----------------------------
  Node-RED                  `http://192.168.10.10:1880`
  Приёмник данных CTRL      `http://192.168.20.20:8080`
  Просмотр истории SQLite   `http://192.168.30.20:8081`
  Prometheus                `http://192.168.30.10:9090`
  Grafana                   `http://192.168.30.10:3000`

## Технологический стек

В проекте применяются следующие инструменты и платформы:

-   **GNS3** --- создание и моделирование виртуальной сети.
-   **РЕД ОС 8** --- операционная система серверных виртуальных машин.
-   **Windows Server 2019** --- операционная система рабочего места
    администратора.
-   **Docker Compose** --- управление запуском контейнерных приложений.
-   **Node-RED** --- эмуляция датчиков и реализация логики управления
    вентилятором.
-   **SQLite** --- база данных для хранения истории показаний.
-   **Prometheus** --- сбор и хранение метрик мониторинга.
-   **Grafana** --- отображение показателей и настройка оповещений.
-   **GitHub** --- размещение исходных файлов, конфигураций и
    документации проекта.

## Запуск и проверка работоспособности

После запуска виртуальной инфраструктуры следует проверить доступность
основных компонентов:

1.  Убедиться, что на IOT запущен контейнер Node-RED.
2.  Проверить работу приёмника данных на CTRL.
3.  Убедиться, что сервис SQLite на DB доступен.
4.  Проверить запуск Prometheus и Grafana на MON.

Контейнеры настроены на автоматический перезапуск. Службы мониторинга
добавлены в автозагрузку.

Для проверки передачи данных необходимо открыть Grafana и убедиться, что
на панели отображаются актуальные показания. Дополнительно в интерфейсе
Prometheus следует проверить, что цель `office-controller` имеет статус
`UP`.

## Итоги проекта

В результате учебной практики разработан прототип системы умного офиса.
В нём реализованы сбор и передача показаний виртуальных датчиков,
автоматическое управление вентилятором, сохранение истории измерений и
мониторинг состояния оборудования.

Система объединяет средства моделирования сети, автоматизации, хранения
данных и визуализации, обеспечивая централизованное наблюдение за
основными параметрами офисного помещения.
